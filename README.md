# Typing Treehouse

A free typing course for kids that runs in any web browser, including Chromebooks.

**Play it:** https://phammthuy25.github.io/typing-treehouse/

- 18 lessons, from the home row (F and J) up to capital letters and full sentences
- On-screen keyboard and hands that show which finger to use for each key
- Stars, a sticker book, and a Balloon Pop letter game
- A progress page with daily minutes, streaks, and best speed and accuracy

Progress is saved in each person's own browser, on that device only. There are no accounts, and no data leaves the computer.

The whole app is the single file `index.html`.
